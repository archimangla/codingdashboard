Build a production-quality full-stack web application called CodeHub (name can be changed) that acts as a universal coding dashboard by aggregating data from multiple competitive programming and coding practice platforms into one personalized analytics dashboard.

The application should require zero manual data entry. The user only provides their profile URLs or usernames once during onboarding. After that, the application automatically fetches and syncs their public activity.

Goal

The purpose of the application is to answer:

What coding problems did I solve today?
Which platform did I use?
Am I maintaining my coding streak?
How many problems have I solved overall?
What topics am I focusing on?
Which difficulty levels am I solving?
How has my consistency changed over time?

It should feel like a personal productivity dashboard rather than just another coding profile viewer.

Important Constraint

The application must gracefully handle platforms that do not expose complete public activity. If certain data cannot legally or technically be retrieved, clearly indicate that limitation in the UI rather than fabricating or estimating data. The architecture should make it easy to add richer integrations in the future as platforms expose new APIs.

The final result should feel like a single unified coding operating system for a programmer, where all coding activity across multiple platforms is automatically consolidated into one personal productivity dashboard with minimal setup.

The AI should discover and integrate the best available official APIs, GraphQL endpoints, or public profile endpoints for each platform. If API credentials are required, automatically generate a .env.example file listing all required environment variables, explain exactly how to obtain each credential with step-by-step instructions, and implement the rest of the integration. The user should only need to paste the credentials if absolutely necessary.
